# PRODIGY_GenAI_Task4

## 📌 Task Overview
This repository contains the implementation of **Task‑04: Image‑to‑Image Translation with cGAN (Pix2Pix)** as part of the Prodigy InfoTech Generative AI Internship.

The objective of this task is to implement an image‑to‑image translation model using a **conditional Generative Adversarial Network (cGAN)** called **Pix2Pix**.  
Pix2Pix learns to translate one type of image into another (e.g., building outlines → realistic facades).
